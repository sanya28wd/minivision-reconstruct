# The free Gemini tier is allowed for the demo and public research clips only

The demo runs on the free Gemini API tier because the project budget is zero. The free tier may let the provider use inputs to improve its products; verify the current terms before relying on this.

That is acceptable for public research-dataset clips. It is not settled for real RTA footage covered by an NDA. Before any real footage is processed, the data-protection and evidence-integrity approach must be agreed with the professor. The options are a paid tier, an approved provider, or a UAE-region deployment.

The model layer is therefore kept swappable. The upload page tells the officer that videos are processed by an external AI service.
